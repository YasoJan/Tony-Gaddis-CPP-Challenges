# 6. Annual Pay

> Suppose an employee gets paid every two weeks and earns $2,200 
> each pay period. In a year the employee gets paid 26 times.

## Variables

| Variable | Description | Initial Value |
|----------|-------------|---------------|
| `payAmount` | Pay earned each period | 2200.0 |
| `payPeriods` | Number of pay periods in a year | 26 |
| `annualPay` | Total annual pay (calculated) | — |

## Goal
Calculate total annual pay by multiplying `payAmount` by `payPeriods` 
and store the result in `annualPay`.
