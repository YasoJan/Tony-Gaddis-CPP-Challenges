# Personal Information

## Problem
Write a program that displays the following pieces of information, each on a
separate line: your name, your address with city, state, and ZIP code, your
telephone number, and your college major. Use only a single cout statement to
display all of this information.

## Variables
No variables used — this program uses only a single `cout` statement with
newline escape characters to display static personal information.

## Expected Output

| Field | Value |
|-------|-------|
| Name | Yasin Zahir |
| Address | 77777 Gold St, Utopia |
| Telephone | +7 (777) 777-777 |
| College Major | Computer Science (AI) |

## Concepts Practiced
- Single `cout` statement with `\n` escape characters for multiple lines
- Selective `using` statements instead of `using namespace std`
- Knowing when to exclude unnecessary headers like `iomanip`
