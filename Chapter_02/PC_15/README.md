# Triangle Pattern

## Problem
Write a program that displays the following pattern on the screen:

         *
        ***
       *****
      *******

## Variables
No variables used — this program uses only a single `cout` statement with
newline escape characters to display a static triangle pattern.

## Expected Output

| Field | Value |
|-------|-------|
| Row 1 | `   *` |
| Row 2 | `  ***` |
| Row 3 | ` *****` |
| Row 4 | `*******` |

## Concepts Practiced
- Single `cout` statement with `\n` escape characters for multiple lines
- Using spaces to create visual alignment and patterns
- Selective `using` statements instead of `using namespace std`
- Knowing when to exclude unnecessary headers like `iomanip`
