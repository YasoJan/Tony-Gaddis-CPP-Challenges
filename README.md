# Tony Gaddis C++ Challenges

Solutions to programming challenges from *Starting Out with C++* 
by Tony Gaddis Eigth Edition.

## About
I'm a CS graduate working through these challenges to sharpen 
my C++ fundamentals. Challenges are completed daily and organized by chapter.

## Structure
Each folder corresponds to a chapter in the book.
- `Chapter_01/`
- `Chapter_02/`
- `Chapter_03/`
- ...and so on

## Topics Covered
- Arrays and 2D Arrays
- Pointers and Memory Management
- Object Oriented Programming
- File I/O
- Vectors and STL
- Classes and Data Abstraction
## Getting Started

### Prerequisites
You'll need g++ installed on your machine.

**macOS:**
```bash
xcode-select --install
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt install g++
```

**Windows:**
Install [MinGW](https://www.mingw-w64.org/) and add it to your PATH.

### Fork & Clone
```bash
# 1. Fork this repo by clicking "Fork" in the top right on GitHub
# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/Tony-Gaddis-CPP-Challenges.git

# 3. Navigate into the repo
cd Tony-Gaddis-CPP-Challenges
```

### Compile & Run
Navigate to any problem set and compile with g++:
```bash
# Example - Chapter 2, Problem Set 4
cd Chapter_02/PC_04

# Compile
g++ main.cpp -o build/output

# Run
./build/output
```
